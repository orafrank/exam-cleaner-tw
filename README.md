# Exam Cleaner TW

將已作答或批改的台灣學校考卷、練習卷與作業單，還原成可再次列印使用的乾淨版本。Skill 以保留原始題目與版面為優先，不會改寫題目或產生解答。

## 安裝與使用

把本儲存庫的 `exam-cleaner-tw` Skill 安裝到 Codex 的 Skills 目錄後，在新對話中附上 JPG、PNG 或 PDF，並說明要清除的內容。可以直接指定 `$exam-cleaner-tw`；若已啟用自動選用 Skill，也可以用自然語言提出需求。

例如：

> 請用 $exam-cleaner-tw 清除這份考卷上的學生答案、姓名、分數和老師批改，保留題目與格線，輸出可列印的版本。

> 請清除這三頁練習卷的學生答案，但保留老師紅筆評語。頁面順序不要改。

## 清除模式

| 模式 | 清除 | 保留 |
| --- | --- | --- |
| 全清模式（預設） | 學生作答、姓名、座號、分數、老師批改 | 原始印刷題目與版面 |
| 保留批改模式 | 學生答案 | 老師紅筆與評語、原始印刷內容 |
| 只清紅筆模式 | 紅筆或彩色批改 | 其他內容 |
| 只清答案模式 | 答案、計算與圈選；未另行指定時也清除個資 | 原始印刷內容；姓名、分數是否保留可另行指定 |

若有特別需要保留的手寫內容，請在送件時說明。多頁文件會逐頁處理，保留原頁序與頁碼。

## 輸入與輸出

- 支援考卷照片、掃描圖（JPG、PNG）及 PDF。
- 優先交付維持原比例的高解析 PNG。需要列印版或輸入為多頁 PDF 時，另提供 A4 PDF；不會為了符合 A4 而拉伸題目。
- 完成時會說明處理頁數、使用模式，以及任何需要人工確認的區域。

## 修復邊界

印刷題目、題號、選項、標點、單位、頁碼、圖表、插圖、作答框與格線都應保留。Skill 不解題、不翻譯、不重新排版，也不會猜測被手寫遮住、無法可靠辨認的原文。如果照片失焦、反光或裁切使重要內容缺失，應補拍原件；不會交付看似完整但可能錯誤的版本。

學生姓名、座號、學號、班級手寫資料與分數預設清除。請只上傳有權處理的文件，並在分享處理結果前自行複查個資與題目完整性。

完整執行規則見 [SKILL.md](SKILL.md)。
